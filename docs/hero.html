github.com/willmather95/ads-guardrail-agent

The agent can ask. The caps decide.

Reads Google Ads and Meta, proposes bid and budget changes with plain-English reasons, and writes only what fits under hard caps. Every write is logged with a hash chain and can be undone.

20% or $50 per change$150/day per account72h cooldownkill switch before every writedry run by default
  1. Read 7 days from the DuckDB warehouse
  2. Propose with a reason and a confidence
  3. Cap through 12 guardrails, all integer math
  4. Check the kill switch and the live value
  5. Write, read back, log with a hash chain
  6. Undo any run with one command
